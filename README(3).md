# Sequence Analysis

A small Python script that reads DNA sequences from a FASTA file and, for each sequence, calculates:

- sequence ID
- length
- GC content (%)
- the corresponding amino acid sequence (translation), in two ways:
  1. plain translation from the first nucleotide
  2. translation starting at the first start codon (AUG)

Results are printed on screen and saved to `results.csv`.

Only the Python standard library is used (no Biopython).

## Project structure

```

├── analyze_sequences.py   # main script
├── sequences.fasta        # input: 5 short DNA sequences
```

## Requirements

- Python 3.6 or newer
- No external packages

## How to run

```bash
python3 analyze_sequences.py
```

The script looks for `sequences.fasta` in the same folder as the script, and writes `results.csv` to the same folder.

## Methods and assumptions

**1. Coding strand.**
All input sequences are assumed to be the **coding (sense) strand**, i.e. the DNA strand whose sequence is identical to the mRNA (with T instead of U). Therefore, they are translated directly, without taking the reverse complement.

**2. GC content.**
`GC% = (G + C) / length * 100`, rounded to 2 decimal places.

**3. Main translation (`aa_sequence`).**
- DNA is converted to RNA (`T` to `U`), then translated codon by codon using the standard genetic code.
- Translation starts from the **first nucleotide** (reading frame 1), regardless of whether a start codon is present.
- Stop codons are shown as `*` and translation **continues** past them, so the full sequence is represented.
- If the length is not divisible by 3, the incomplete last codon is ignored.
- A codon with an unknown character is shown as `X`.

**4. Translation considering the start codon (`orf_protein`).**
- The script finds the **first start codon (AUG, i.e. ATG in DNA)**.
- Translation starts there and **stops at the first stop codon** (the stop codon is not included).
- If no start codon exists, the `orf_protein` column in the CSV is left empty, and the screen output reports "No start codon (AUG) found".

| id   | Start position (1-based) | Protein (from start codon) |
|------|--------------------------|----------------------------|
| seq1 | 1                        | MRTLADRC                   |
| seq2 | not found                | -                          |
| seq3 | 8                        | MLARLTLAD                  |
| seq4 | not found                | -                          |
| seq5 | 10                       | MLA                        |

**5. CSV columns.**
The exercise text lists the columns as `AA Sequence id,length,gc_percent`. I used the order `id,length,gc_percent,aa_sequence`, and added one extra column, `orf_protein`, for the start-codon-based translation.

**6. Limitations.**
Only the forward (coding) strand is analyzed. Other reading frames, the reverse complement, and multiple ORFs per sequence are not considered. Only the first AUG is used.
